# Terminal

## Comandos importantes

- cd → mudar de pasta
- mkdir → criar pasta
- code . → abrir VS Code
# 10 comandos úteis do Terminal

1. pwd → mostra a pasta atual onde estou
2. ls → lista ficheiros e pastas
3. cd → muda de pasta
4. mkdir → cria uma nova pasta
5. touch → cria um ficheiro
6. rm → remove ficheiros
7. cp → copia ficheiros
8. mv → move ou renomeia ficheiros
9. clear → limpa o terminal
10. git status → mostra o estado do repositório Git
